MĀA — Restaurant Portfolio Website

HOW TO RUN
1. Extract the ZIP folder.
2. Open the maa-restaurant-portfolio folder in VS Code.
3. Open index.html with Live Server (recommended), or double-click index.html.
4. Keep the images folder beside index.html.

FILES
- index.html: website structure and content
- style.css: layout, responsive design, colours and animations
- script.js: mobile navigation, scroll reveal, demo reservation form
- images/: your supplied reference images, copied into the project

CUSTOMIZE
- Search and replace MĀA to change the restaurant name.
- Edit address, phone, email, hours and menu prices in index.html.
- Replace images inside images/ (keep the same filenames, or update their paths in HTML/CSS).
- The reservation form is a front-end demo only. Connect a backend or booking service to receive real reservations.
